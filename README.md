# Reproductive_modes_mutation_rate
Data and code related to the paper "Reproductive mode and the evolution of mutation rate"

# Folders content:

1. dS folder:
Contains one file ("ds_scripts.txt") describing the steps to obtain the dS values. 

2. models folder:
Files:
facultative.py: Python code needed to run simulations.
invasion.ipynb: Jupyter notebook with the simulations used to construct figure 2 but run at 10% the level of replication. Output of simulations is shown.
figure2_data.csv: Data extracted from the simulations shown in invasion.ipynb.
figure2.ipynb: Jupyter notebook showing how to make figure 2 from the data.
figure2_low_res.pdf: The resulting figure.  It is like a low resolution version of the figure in the paper because of the lower sample size in the invasion simulations (hence the wider 95% CIs).
